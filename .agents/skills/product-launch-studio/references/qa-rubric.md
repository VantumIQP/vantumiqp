# QA Rubric

Run separate checks for workspace structure, evidence, claims, manifest
schema, editorial quality, platform readiness, asset provenance,
accessibility, visual correctness, text overflow, editability, static
rendering, video rendering, sensitive information, and unresolved TODOs.

## Editorial Checks

Flag unsupported facts, altered claim wording, lost qualifications, vague
hype, fake urgency, fake social proof, unsupported comparisons, weak CTA,
audience mismatch, locale mixing, awkward translation, excessive hashtags,
and obvious AI-writing patterns.

## Visual Checks

Check canvas dimensions, margins, grid, hierarchy, legibility, overflow,
clipping, orphaned text, screenshot resolution, logo use, border radii,
colors, font substitution, contrast, density, CTA visibility, page order,
preview consistency, and asset provenance.

## Report

Produce blocking errors, warnings, review items, commands run, outputs
reviewed, and items requiring owner approval. Do not claim visual review or
full video review unless actually performed.
