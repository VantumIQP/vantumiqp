# Editable Vector Assets

Use SVG for editable title cards, labels, callouts, arrows, workflow
diagrams, logo treatments, lower thirds, overlays, and end-card elements.
Screenshots, recordings, photographs, and final video files may remain raster.

## Requirements

- SVG variants retain live text.
- Avoid `foreignObject`, scripts, unresolved external references, and
  full-slide raster-only compositions.
- Use named groups for important layers.
- Store editable source files separately from PNG and PDF derivatives.
- Document fonts, fallbacks, and import-test status.
- Do not mark external import compatibility as tested without evidence.
